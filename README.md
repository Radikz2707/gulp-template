# 🚀 Gulp Professional Template (v2.0)

Современный, быстрый и полностью автоматизированный шаблон для профессиональной верстки. Построен на компонентном подходе (BEM) с использованием Gulp 5, Webpack 5 и современных стандартов Sass (@use).

---

## 🛠 Команды проекта


| Команда | Описание |
| :--- | :--- |
| `npm run dev` | **Запуск разработки:** очистка `dist`, генерация фавиконок, шрифтов и старт сервера. |
| `npm run build` | **Финальный билд:** линтинг, сжатие ресурсов, очистка CSS и создание ZIP-архива. |
| `npm run lint` | **Контроль качества:** проверка всех JS и SCSS файлов на ошибки. |
| `gulp create --name` | **Конструктор блока:** генерирует HTML/SCSS/JS/IMG и подключает везде. |
| `gulp remove --name` | **Деструктор блока:** удаляет папку и вырезает все импорты из проекта. |
| `gulp help` | **Шпаргалка:** выводит список всех команд прямо в терминал. |

## 🏗 Автоматизация компонентов (BEM)

Шаблон реализует полный цикл управления независимыми модулями:

- **Создание**: Команда `gulp create --header` создает папку в `src/components/header/`, в которой уже лежат:
  - `header.html` (с готовым контейнером);
  - `header.scss` (пустой селектор);
  - `header.js` (модуль с инициализацией);
  - `img/` (папка для графики, специфичной для этого блока).
- **Авто-подключение**: Блок автоматически регистрируется в:
  - `src/index.html` — добавляется `@@include`;
  - `src/js/app.js` — добавляется `import` и вызов функции;
  - `src/scss/main.scss` — добавляется современный `@use`.
- **Удаление**: Команда `gulp remove --header` корректно удаляет папку и **полностью вырезает** все упоминания блока из файлов проекта, предотвращая ошибки сборки.

## ⚙️ Особенности и технологии

### 💎 Качество кода
- **HTML Accessibility**: Автоматическая проверка на доступность (обязательный `alt` у изображений, уникальность `id`).
- **HTML Beautify**: Итоговый код в `dist` всегда имеет идеальные отступы и вложенность.
- **Sass @use**: Использование современной модульной системы Sass вместо устаревшего `@import`.

### 🖼 Работа с графикой
- **Component Images**: Картинки хранятся внутри папок блоков. Сборщик автоматически оптимизирует их и «сплющивает» в единую папку `dist/images/`.
- **Smart WebP**: Автоматическая генерация WebP и замена тегов `img` на `picture`. В коде используйте путь: `<img src="images/filename.jpg">`.
- **Favicons**: Генерация полного набора иконок для iOS, Android и десктопа из одного исходника `src/images/src/favicon.png`. Ссылки подключаются автоматически.

### 🚀 Технический стек
- **Webpack 5 + Babel**: Сборка JS-модулей с поддержкой старых браузеров.
- **Gulp 5**: Новейшая версия системы сборки с высокой скоростью работы.
- **Smart Refresh**: CSS обновляется без перезагрузки (stream), остальное — с перезагрузкой страницы.
- **Clean Start**: Полная очистка папки `dist` при каждом запуске для удаления «мусорных» файлов.

## 📝 Важные примечания
1. **Шрифты**: Исходные шрифты в формате `.ttf` или `.otf` кладите в `src/fonts/src/`. Сборщик сам сконвертирует их в `.woff` / `.woff2` и автоматически создаст файл стилей `_fonts.scss`.
2. **Иконки**: Для создания SVG-спрайта просто кладите иконки в корень `src/images/src/`. Файл `sprite.svg` соберется автоматически.
3. **Favicon**: Исходник для фавиконок должен называться `favicon.png` и лежать в `src/images/src/`. При первом запуске скрипт создаст набор иконок и файл с линками в `src/parts/`.
