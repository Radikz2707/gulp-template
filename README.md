# 🚀 Gulp + TypeScript Professional Template (v2.1)

Современный, быстрый и полностью автоматизированный шаблон для профессиональной верстки. Построен на компонентном подходе (BEM) с использованием Gulp 5, Webpack 5 и **TypeScript**.

---

## 🚀 Быстрый старт (Развертывание нового проекта)

Чтобы начать новый проект на основе этого шаблона, выполните следующие команды в терминале:

1. **Клонируйте шаблон** в новую папку (точка в конце важна):
   ```bash
   git clone git@github.com:Radikz2707/gulp-template.git .
   ```
2. **Удалите связь с репозиторием шаблона**:
   ```bash
   rm -rf .git
   ```
3. **Установите зависимости**:
   ```bash
   npm install --registry=https://npmmirror.com --legacy-peer-deps
   ```
4. **Инициализируйте структуру** и запустите сервер:
   ```bash
   npm run init && npm run dev
   ```

## 🛠 Команды проекта


| Команда | Описание |
| :--- | :--- |
| `npm run dev` | **Запуск разработки:** очистка `dist`, генерация фавиконок, шрифтов и старт сервера. |
| `npm run build` | **Финальный билд:** линтинг, сжатие, группировка медиа-запросов и ZIP-архив с датой. |
| `npm run lint` | **Контроль качества:** проверка всех **TS**, SCSS и HTML файлов на ошибки. |
| `gulp create --name` | **Конструктор блока:** генерирует HTML/SCSS/**TS**/IMG в `src/components/`. |
| `gulp module --name` | **Конструктор модуля:** создает **TS**/SCSS в `src/js/modules/` для логики. |
| `gulp remove --name` | **Универсальный деструктор:** удаляет папку (блок/модуль) и вырезает все импорты. |

---

## 🏗 Автоматизация и BEM

Шаблон реализует полный цикл управления независимыми модулями:

- **Авто-подключение**: При создании блока он автоматически регистрируется в `src/index.html`, `src/js/app.ts` и `src/scss/style.scss`.
- **Умное удаление**: Команда `remove` проверяет папки `components`, `modules` и `plugins`. Системные директории защищены от случайного удаления.
- **TypeScript Aliases**: Настроены алиасы `@` (для `src/js`) и `@comp` (для `src/components`) для чистых импортов.

## ⚙️ Особенности и технологии

### 💎 Качество кода
- **TypeScript**: Полная поддержка компиляции и проверки типов.
- **Линтинг**: ESLint (с поддержкой TS), Stylelint и HTMLHint настроены на строгую проверку.
- **Prettier**: Автоматическое форматирование кода при сохранении.
- **Sass @use**: Модульная система стилей без устаревшего `@import`.

### 🖼 Работа с графикой
- **Smart WebP**: Автоматическая генерация WebP и замена тегов в HTML.
- **SVG Спрайты**: Умная очистка иконок через `cheerio` (сохраняет `fill="none"` для прозрачности).
- **PWA Favicons**: Генерация полного набора иконок для всех устройств из одного файла `favicon.png`.

---

## 📝 Важные примечания
1. **TypeScript**: Главный файл входа — `src/js/app.ts`. Все импорты в TS пишутся без расширения `.js` или `.ts`.
2. **Шрифты**: Исходники (`.ttf` / `.otf`) кладите в `src/fonts/src/`. Сборщик сконвертирует их и создаст `_fonts.scss`.
3. **Иконки**: Кладите иконки в `src/images/src/`. Файл `sprite.svg` соберется автоматически.
