# 🚀 Gulp Professional Template (v2.0)

Современный, быстрый и полностью автоматизированный шаблон для профессиональной верстки. Построен на компонентном подходе (BEM) с использованием Gulp 5, Webpack 5 и современных стандартов Sass (@use).

---

## 🛠 Команды проекта


| Команда | Описание |
| :--- | :--- |
| `npm run dev` | **Запуск разработки:** очистка `dist`, генерация фавиконок, шрифтов и старт сервера. |
| `npm run build` | **Финальный билд:** линтинг, сжатие ресурсов, очистка CSS и создание ZIP-архива. |
| `npm run lint` | **Контроль качества:** проверка всех JS и SCSS файлов на ошибки. |
| `gulp create --name` | **Конструктор блока:** генерирует HTML/SCSS/JS/IMG в `src/components/` и подключает везде. |
| `gulp module --name` | **Конструктор модуля:** создает JS/SCSS в `src/js/modules/` для логики (слайдеры, табы). |
| `gulp remove --name` | **Универсальный деструктор:** удаляет папку (блок/модуль/плагин) и вырезает все импорты. |
| `gulp help` | **Шпаргалка:** выводит список всех команд прямо в терминал. |

---

## 🏗 Автоматизация компонентов и модулей

Шаблон реализует полный цикл управления независимыми частями проекта:

- **Создание блока**: Команда `gulp create --header` создает структуру в `src/components/header/` (HTML, SCSS, JS, IMG).
- **Создание модуля**: Команда `gulp module --tabs` создает логику в `src/js/modules/tabs/` (JS, SCSS).
- **Авто-подключение**: Компоненты автоматически регистрируются в:
  - `src/index.html` — добавляется `@@include`;
  - `src/js/app.js` — добавляется `import` и вызов функции;
  - `src/scss/style.scss` — добавляется современный `@use`.
- **Умное удаление**: Команда `gulp remove --name` автоматически находит папку в `components`, `modules` или `plugins` и полностью вырезает упоминания из кода. Системные директории защищены от удаления.

## ⚙️ Особенности и технологии

### 💎 Качество кода
- **HTML Accessibility**: Автоматическая проверка на доступность (обязательный `alt` у изображений, уникальность `id`).
- **HTML Beautify**: Итоговый код в `dist` всегда имеет идеальные отступы и вложенность.
- **Sass @use**: Использование современной модульной системы Sass вместо устаревшего `@import`.

### 🖼 Работа с графикой
- **Component Images**: Картинки могут храниться внутри папок блоков. Сборщик автоматически оптимизирует их и собирает в `dist/images/`.
- **Smart WebP**: Автоматическая генерация WebP и замена тегов `img` на `picture`.
- **Favicons**: Генерация полного набора иконок из одного исходника `src/images/src/favicon.png`.

### 🚀 Технический стек
- **Webpack 5 + Babel**: Сборка JS-модулей с поддержкой старых браузеров и поддержкой алиасов (`@/`).
- **Gulp 5**: Новейшая версия системы сборки с высокой скоростью работы.
- **Clean Start**: Полная очистка папки `dist` при каждом запуске для удаления «мусорных» файлов.

## 📝 Важные примечания
1. **Шрифты**: Исходники (`.ttf` / `.otf`) кладите в `src/fonts/src/`. Сборщик сконвертирует их и создаст `_fonts.scss`.
2. **Иконки**: Для создания SVG-спрайта кладите иконки в `src/images/src/`. Файл `sprite.svg` соберется автоматически.
3. **Конфигурация**: Все пути и настройки (качество WebP, автопрефиксер) меняются в `gulp.config.js`.
